# Public release checklist

- [ ] Initialize Git and commit only source, documentation, and small example data.
- [ ] Add the approved license, author list, ORCID links, paper title, DOI, and URL.
- [ ] Replace all `CITATION.cff` placeholders.
- [ ] Scan history and files for API keys, private paths, tokens, model weights, and data.
- [ ] Confirm redistribution rights for every dependency, dataset reference, and figure.
- [ ] Run the README workflow from a clean clone and a clean environment.
- [ ] Tag the exact version used for the camera-ready paper.
- [ ] Archive the release (for example, with Zenodo) and add its DOI to the paper.
